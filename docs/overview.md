# UHFC Sports Complex Website - Project Overview

## Introduction
The UHFC Sports Complex website is a modern, visually striking platform designed to showcase the facilities, events, and coaching staff of the complex. It features a "dark mode" aesthetic with vibrant "Electric Pitch Green" accents, emphasizing a premium and energetic sports atmosphere.

## Technical Stack
- **Framework**: Next.js 14+ (App Router)
- **Styling**: Standard CSS (Global styles + CSS Variables), Inline styles for dynamic components.
- **Animations**: `framer-motion` for entrance animations and interactions.
- **Scrolling**: `lenis/react` for smooth scrolling behavior.
- **Language**: TypeScript (`.tsx`, `.ts`)

## Key Features
- **Responsive Design**: Fully responsive layout for all device sizes.
- **Smooth Scrolling**: Lenis integration for a premium feel.
- **Scroll Spy Navigation**: Active section highlighting in the navbar.
- **Interactive Components**: Hover effects, customized cursors (if applicable), and dynamic content reveals.
