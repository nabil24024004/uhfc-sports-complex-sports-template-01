# Design System

## Color Palette
The design relies on a high-contrast dark theme with a signature electric green accent.

| Variable | Value | Description |
| :--- | :--- | :--- |
| `--background` | `#080c14` | Deep dark blue/black background. |
| `--surface` | `rgba(20, 25, 35, 0.7)` | Semi-transparent dark surface for cards/panels. |
| `--accent` | `#a8ff00` | "Electric Pitch Green" - primary action/highlight color. |
| `--text` | `#ffffff` | Primary text color. |
| `--text-muted` | `#a0a0a0` | Secondary text color. |

## Typography
Three primary font families are used to create hierarchy and character.

- **Display**: `Michroma` (Headings, Buttons, Brand Identity)
- **Body**: `Syne` (Subheadings, Stylized text)
- **Content**: `Outfit` (Paragraphs, Readable content)

## Layout & Spacing
- **Container Width**: Fluid container with max-width constraints (typically `5%` padding on sides).
- **Section Padding**: `8rem` vertical padding for distinct section separation.
- **Grid System**: Responsive grids used for features, gallery, and news sections.

## Visual Effects
- **Noise Texture**: A subtle SVG noise filter overlay on the `body` to add texture.
- **Gradients**: Radial gradients used in the background to create depth.
- **Glassmorphism**: Backdrop blur used on the sticky navbar.
